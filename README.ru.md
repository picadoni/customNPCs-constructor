# CustomNPCs-constructor
Визуальный конструктор диалогов, квестов и скриптов для мода Custom NPCs в Minecraft.

## История версий (Кликабельно 🌐)

### [Версия 0.0](https://github.io)
**Конструктор диалогов CustomNPCs «Глашатай»**
* **Начало проекта:** Создание вкладок для проектирования диалогов.

### [Версия 0.1](https://github.io)
**Конструктор диалогов CustomNPCs «Звездочёт»**
* **Обновление:** Добавлено 5 разных тем/стилей оформления интерфейса.

### [Версия 0.2](https://github.io)
**Конструктор диалогов CustomNPCs «Управитель»**
* **Обновление:** Добавлены 4 кнопки управления:
  1. Очистить всё
  2. Удалить последнюю
  3. Добавить ветку
* **Заметка:** Добавлена иконка дискеты для скачивания диалога, но она ещё не функционирует (заготовка). Скачивание пока происходит при нажатии на нижнюю кнопку.

### [Версия 0.3](https://github.io)
**Конструктор диалогов CustomNPCs «Смотритель»**
* **Обновление шестерёнки:**
  1. Создание дополнительного диалога (добавлена кнопка, пока функционал в виде заготовки).
  2. Уровень доступа (добавлена кнопка, пока функционал в виде заготовки).
* **Нововведения:** Добавлен блокнот для записей с 3 вкладками и функцией поиска по записям:
  1. Сюжет
  2. Задания
  3. Памятки

### [Версия 0.4](https://github.io)
**Конструктор диалогов CustomNPCs «Учёный»**
* **Обновление шестерёнки:** Функция создания дополнительного диалога доведена до полностью рабочей версии.

### [Версия 0.5](https://github.io)
**Конструктор диалогов CustomNPCs «Мастер»**
* **Обновление блокнота:** Теперь он стал выдвижным и больше не нагромождает интерфейс.
* **Расширение функционала:** Появилась возможность создавать до 34 веток ответов/диалогов в одном окне для дополнительного диалога. Добавлены кнопки управления: «Очистить всё», «Удалить последнюю», «Добавить ветку».

### [Версия 0.6](https://github.io)
**Конструктор диалогов CustomNPCs «Молния»**
* **Удалено:** Полностью убрана большая кнопка «Скачать файл диалога (.JSON)».
* **Изменения:** Темы и другие настройки перенесены внутрь меню шестерёнки.
* **Нововведения:** 
  1. Возможность изменять прозрачность интерфейса.
  2. Возможность установить собственное изображение на задний фон.
* **Шаблоны:** Добавлены пресеты для быстрого заполнения: «Житель», «Стража», «Торговец».
* **Оптимизация:** Добавлена возможность полностью свернуть окна диалогов ID1, ID2 и т.д., избавившись от отдельно висящих окон и вкладок.

### [Версия 0.7](https://github.io)
**Конструктор диалогов «Бригадир» (v0.7) / Конструктор заданий «Бригадир» (v0.1)**
* **Нововведения:** Добавлена вкладка «Создание заданий» (Quests).
* **Заготовки:** Создана шестерёнка на будущее во вкладке квестов.
* **Обновление диалогов:** Настроена система условий доступности (Dialogs).

### [Версия 0.8](https://github.io)
**Конструктор диалогов «Диктор» (v0.8) / Конструктор заданий «Ацтек» (v0.2)**
* **Обновление интерфейса:** 
  1. Добавлена возможность сбросить кастомную картинку заднего фона, загруженную с ПК.
  2. Добавлена стрелка для быстрой промотки страницы вверх/вниз.
* **Обновление заданий:**
  * Активирована шестерёнка: теперь можно создавать дополнительные ветки заданий.
  * Увеличено количество доступных заданий, а также исправлена ошибка в структуре файла задания (ранее игра могла не распознавать файл).
  * Добавлена возможность автоматического ввода консольной команды при завершении задания (аналогично функционалу самого мода).

### [Версия 0.9](https://github.io)
**Конструктор диалогов «Комета» (v0.9) / Конструктор заданий «Сателлит» (v0.3)**
* **Нововведения:** Добавлен полноценный справочник консольных команд игры со встроенным поиском по названиям.
* **Исправления:** Доработана вкладка заданий и оптимизирована логика их завершения.
* **Оптимизация:** Добавлена возможность в один клик ввести команду после выбора окна команды в конструкторе диалогов или заданий.

### [Версия 1.0](https://github.io)
**Конструктор диалогов «Комета» (v0.9) / Конструктор заданий «Сателлит» (v0.3) / Скриптовый модуль «Император» (v0.1)**

* **Шаблоны скриптов:** Добавлены заготовки для автоматической генерации кода и библиотека готовых JavaScript-скриптов:
  1. Автогенератор скрипта
  2. Готовые скрипты: сказать в чат, воспроизвести звук, вызов частиц, выдать эффект зелья, случайное событие.
* **Известный баг:** Окно заданий подсвечивается как активное, даже когда пользователь находится в окне скриптового модуля.
