# CustomNPCs-constructor
Minecraftの「Custom NPCs」モッドに対応した、対話、クエスト、スクリプトのビジュアルコンストラクター。

## バージョン履歴 (クリック可能 🌐)

### [バージョン 0.0](https://picadoni.github.io/customNPCs-constructor/ver%200.0/)
**CustomNPCs 对話コンストラクター「Herald」(グラシャタイ)**
* **プロジェクト開始:** 対話を設計するための基本タブを追加。

### [バージョン 0.1](https://picadoni.github.io/customNPCs-constructor/ver%200.1/)
**CustomNPCs 对话コンストラクター「Stargazer」(ズヴェズドチョット)**
* **アップデート:** 5種類のUIテーマ/スタイルを追加。

### [バージョン 0.2](https://picadoni.github.io/customNPCs-constructor/ver%200.2/)
**CustomNPCs 対話コンストラクター「Steward」(ウプラヴィーテリ)**
* **アップデート:** 4つの操作ボタンを追加:
  1. すべてクリア
  2. 最後の項目を削除
  3. ブランチを追加
* **注意:** 対話ダウンロード用のフロッピーディスクアイコンを追加しましたが、まだ機能しません（プレースホルダー）。現在は下部ボタンからダウンロードが行われます。

### [バージョン 0.3](https://picadoni.github.io/customNPCs-constructor/ver%200.3/)
**CustomNPCs 対話コンストラクター「Warden」(スモトリーテリ)**
* **設定（歯車）メニューの更新:**
  1. 追加の対話作成（ボタンを追加、機能はプレースホルダー）。
  2. アクセスレベル（ボタンを追加、機能はプレースホルダー）。
* **新機能:** 3つのタブと検索機能を備えたメモ帳を追加:
  1. ストーリーライン
  2. クエスト
  3. メモ

### [バージョン 0.4](https://picadoni.github.io/customNPCs-constructor/ver%200.4/)
**CustomNPCs 対話コンストラクター「Scientist」(ウチョーヌィ)**
* **設定（歯車）メニューの更新:** 「追加の対話作成」機能が完全に動作するようになりました。

### [バージョン 0.5](https://picadoni.github.io/customNPCs-constructor/ver%200.5/)
**CustomNPCs 対話コンストラクター「Master」(マスター)**
* **メモ帳の更新:** インターフェースが煩雑になるのを防ぐため、スライド式のパネルに変更。
* **機能拡張:** 追加の対話で、1つのウィンドウ内に最大34個の応答/対話ブランチを作成できるようになりました。操作ボタン（「すべてクリア」、「最後の項目を削除」、「ブランチを追加」）を追加。

### [バージョン 0.6](https://picadoni.github.io/customNPCs-constructor/ver%200.6/)
**CustomNPCs 対話コンストラクター「Lightning」(モールниヤ)**
* **削除:** 巨大な「対話ファイルをダウンロード (.JSON)」ボタンを完全に削除。
* **変更:** テーマやその他の設定を歯車メニュー内に移動。
* **新機能:** 
  1. UIの透明度調整機能。
  2. PCからカスタム背景画像を設定できる機能。
* **テンプレート:** 素早く入力するためのプリセットを追加:「村人」、「衛兵」、「商人」。
* **最適化:** 对話ウィンドウ（ID1、ID2など）を完全に折りたたむことができるようになり、独立したフローティングウィンドウを廃止。

### [バージョン 0.7](https://picadoni.github.io/customNPCs-constructor/ver%200.7/)
**対話コンストラクター「Foreman」(v0.7) / クエストコンストラクター「Foreman」(v0.1)**
* **新機能:**「クエスト作成 (Quests)」タブを追加。
* **プレースホルダー:** 将来のクエスト設定用歯車メニューの枠組みを作成。
* **対話の更新:** 対話の「利用条件 (Availability Conditions)」システムを実装。

### [バージョン 0.8](https://picadoni.github.io/customNPCs-constructor/ver%200.8/)
**対話コンストラクター「Announcer」(v0.8) / クエストコンストラクター「Aztec」(v0.2)**
* **UIの更新:** 
  1. カスタムPC背景画像をリセットするオプションを追加。
  2. ページを素早く上下スクロールするための矢印を追加。
* **クエストの更新:**
  * 歯車メニューを有効化: クエストの追加ブランチが作成可能に。
  * 作成可能なクエスト数を増やし、ゲームがクエストファイルを認識できなくなる構造上のバグを修正。
  * クエスト完了時にコンソールコマンドを実行するオプションを追加（モッドのネイティブ機能に対応）。

### [バージョン 0.9](https://picadoni.github.io/customNPCs-constructor/ver%200.9/)
**対話コンストラクター「Comet」(v0.9) / クエストコンストラクター「Satellite」(v0.3)**
* **新機能:** 名前による検索機能を統合した、包括的なゲームコマンドガイドを追加。
* **修正:** クエストタブを修正し、クエスト完了ロジックを最適化。
* **最適化:** 対話/クエストコンストラクターでコマンドウィンドウを選択後、1クリックでコマンドを挿入可能に。

### [バージョン 1.0](https://picadoni.github.io/customNPCs-constructor/ver%201.0/)
**対話コンストラクター「Comet」(v0.9) / クエストコンストラクター「Satellite」(v0.3) / スクリプトモジュール「Emperor」(v0.1)**
*（対話およびクエストコンストラクターは、このリリースで機能更新がなかったため、新しい名前は付けられていません）。*
* **新機能:** 新しいタブ「CustomNPCs スクリプトモジュール 'Emperor' v0.1」を追加。
* **スクリプトテンプレート:** 自動生成テンプレートと、すぐに使えるJavaScriptコードプリセットライブラリを追加:
  1. スクリプト自動生成器
  2. プリセットスクリプト: チャットで発言、サウンド再生、パーティクル呼び出し、ポーション効果付与、ランダムイベント。
* **既知のバグ:** スクリプトモジュールウィンドウ内で操作しているときも、クエストウィンドウがアクティブとしてハイライトされたままになる。
